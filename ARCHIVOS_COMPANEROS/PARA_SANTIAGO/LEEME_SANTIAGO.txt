====================================================================
INSTRUCCIONES PARA SANTIAGO AVILA (MASCOTAS, HISTORIALES, DIAGNOSTICOS, MEDICAMENTOS Y RECORDATORIOS)
====================================================================

Hola Santiago, en esta entrega estas a cargo del modulo de expedientes clinicos y farmacologia:
Mascotas, Historiales Medicos, Diagnosticos, Medicamentos y Recordatorios.

TUS ARCHIVOS ASIGNADOS:
--------------------------------------------------------------------
1. Modelos (src/models/):
   - Mascota.js
   - HistorialMedico.js
   - Diagnostico.js
   - Medicamento.js
   - Recordatorio.js

2. Controladores (src/controllers/):
   - mascotasController.js
   - historialesController.js
   - diagnosticosController.js
   - medicamentosController.js
   - recordatoriosController.js

3. Rutas (src/routes/):
   - mascotasRoutes.js
   - historialesRoutes.js
   - diagnosticosRoutes.js
   - medicamentosRoutes.js
   - recordatoriosRoutes.js

REGLAS DE NEGOCIO IMPLEMENTADAS:
- RN-01: Toda mascota debe estar asociada obligatoriamente a un propietario registrado.
- RN-03: Codigo chip / identificador unico por mascota.
- RN-04: Autocreacion automatica del historial clinico al registrar la mascota.
- RN-09: Formulacion de medicamentos controlada dentro de consultas.
- RN-11: Borrado logico (activo = false) si la mascota tiene historial clinico.
- RF-15: Emision de reporte oficial consolidado imprimible.

PASO A PASO PARA SUBIR TU TRABAJO A GITHUB:
--------------------------------------------------------------------
1. Abre tu terminal en tu computador y clona el repo de Enoc:
   git clone https://github.com/Enoc-TM/medimascotas-backend.git
   cd medimascotas-backend
   npm install

2. Crea tu rama personal:
   git checkout -b feature/santiago-mascotas-historial-diagnosticos

3. Copia los archivos de este paquete 'PARA_SANTIAGO/src/' y pegalos en la carpeta 'src/' de tu repositorio.

4. Ejecuta las pruebas automatizadas para verificar que todo funcione:
   node tests/api.test.js

5. Sube tu rama a GitHub:
   git add .
   git commit -m "feat(santiago): implementacion de modelos, controladores y rutas para Mascotas, Historiales, Diagnosticos, Medicamentos y Recordatorios"
   git push -u origin feature/santiago-mascotas-historial-diagnosticos

6. Abre el Pull Request en GitHub hacia la rama 'main' y avisale a Enoc para el Merge.
