====================================================================
INSTRUCCIONES PARA ESTEBAN FIERRO (CONSULTAS, TRATAMIENTOS Y VACUNAS)
====================================================================

Hola Esteban, en esta entrega estas a cargo del modulo de atencion medica:
Consultas Veterinarias, Tratamientos y Vacunas (Carnet de Inmunizacion).

TUS ARCHIVOS ASIGNADOS:
--------------------------------------------------------------------
1. Modelos (src/models/):
   - Consulta.js
   - Tratamiento.js
   - Vacuna.js

2. Controladores (src/controllers/):
   - consultasController.js
   - tratamientosController.js
   - vacunasController.js

3. Rutas (src/routes/):
   - consultasRoutes.js
   - tratamientosRoutes.js
   - vacunasRoutes.js

REGLAS DE NEGOCIO IMPLEMENTADAS:
- RN-05: Solo se pueden registrar consultas a mascotas existentes y activas.
- RN-06: Cada consulta debe estar asociada a un veterinario valido.
- RN-07: Cada consulta requiere al menos un diagnostico para ser valida.
- RN-08: Todo tratamiento debe estar vinculado a un diagnostico existente.
- RN-10: Las vacunas solo pueden aplicarse a mascotas registradas.
- RN-15: Coherencia de fechas en consultas y vacunacion.

PASO A PASO PARA SUBIR TU TRABAJO A GITHUB:
--------------------------------------------------------------------
1. Abre tu terminal en tu computador y clona el repo de Enoc:
   git clone https://github.com/Enoc-TM/medimascotas-backend.git
   cd medimascotas-backend
   npm install

2. Crea tu rama personal:
   git checkout -b feature/esteban-consultas-vacunas-tratamientos

3. Copia los archivos de este paquete 'PARA_ESTEBAN/src/' y pegalos en la carpeta 'src/' de tu repositorio.

4. Ejecuta las pruebas automatizadas para verificar que todo funcione:
   node tests/api.test.js

5. Sube tu rama a GitHub:
   git add .
   git commit -m "feat(esteban): implementacion de modelos, controladores y rutas para Consultas, Tratamientos y Vacunas"
   git push -u origin feature/esteban-consultas-vacunas-tratamientos

6. Abre el Pull Request en GitHub hacia la rama 'main' y avisale a Enoc para el Merge.
